# PrimeVue / Vue reference docs

이 폴더는 PrimeVue와 Vue 관련 참고 문서다. eduSSAFY 클론의 1차 기준 문서가 아니다.

## 사용 목적

- Table, Paginator, Dialog, FileUpload, Accordion 등 PrimeVue 컴포넌트 사용법 확인
- Vue/Vite 설치, CLI, 설정 참고
- 구현 중 라이브러리 API가 필요할 때만 조회

## 기준 우선순위

1. `../../FRAME.md`
2. `../../DESIGN.md`
3. `../app-vue/`
4. 현재 `reference-primevue/`

## 폴더 구성

```text
reference-primevue/
├── root/                 # 이전 루트 PrimeVue 문서
├── components/           # PrimeVue component reference
├── installation/         # 설치 가이드
├── guides/               # 사용 가이드
├── reference/            # 기타 reference
└── 30-components-index/  # component index
```

## 주의

- 여기 있는 컴포넌트 문서는 SSAFY 화면 배치 기준이 아니다.
- PrimeVue 스타일이 `DESIGN.md`와 다르면 `DESIGN.md`를 따른다.
- 페이지 구조/라우팅/클릭 이동은 `FRAME.md`를 따른다.
